# AAPL Historical Price Analysis

## Project objective
Explore Apple (AAPL) historical stock prices and daily returns using Python.

## Questions
- How did AAPL's adjusted price change over the dataset period?
- How much did daily returns vary?
- What were the largest daily increase and decrease?

## Tools
- Python
- pandas
- Matplotlib
- Jupyter Notebook

## Key findings
- Dataset period: January 2, 2020 to November 17, 2026.
- Largest daily increase: 15.33% on April 9, 2025.
- Largest daily decrease: -12.86% on March 16, 2020.

These are historical observations. They do not explain the cause of each price move or predict future performance.

## Data
Historical AAPL data downloaded from Yahoo Finance. The data file is not included in this repository.

To run the notebook, download the historical data and place the Excel file beside the notebook using the filename expected by the code.

## Limitations
This project analyzes one company and does not compare its returns with a market benchmark.
